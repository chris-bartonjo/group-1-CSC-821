# CSC 821 — Module 10: NP-Completeness (Group 1)

Lab activity: **Vertex Cover** — its formal definition, why it's NP-complete (membership
in NP plus a polynomial-time reduction from 3-SAT), and a greedy 2-approximation solver,
with worked examples, a correctness check of the reduction, and sample input/output.

## Files
- `module_10_np_completeness.ipynb` — the notebook, runs top to bottom.
- `module_10_np_completeness.pdf` — rendered PDF of the executed notebook.

## Run
```
jupyter notebook module_10_np_completeness.ipynb
```
or simply open the PDF.
