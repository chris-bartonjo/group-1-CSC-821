# CSC 821 — Module 7: Huffman Coding (Group 1)

Lab activity: a Python implementation of **Huffman coding** — build the tree, generate the
prefix codes, encode, and decode — with step-by-step explanations, two worked examples,
a compression analysis, and a single-character edge-case test.

## Files
- `module_7_huffman_coding.ipynb` — the notebook, runs top to bottom.
- `module_7_huffman_coding.pdf` — rendered PDF of the executed notebook.

## Run
```
jupyter notebook module_7_huffman_coding.ipynb
```
or simply open the PDF.
